# ADR-010 — Une branche de livraison pour la construction initiale

- Statut : Accepté
- Date : 2026-11-04

- Le brief demande « une tâche = une branche = une PR ». L’environnement de cette première session impose une branche de développement unique (`claude/awesome-goodall-y5u3kg`).
- Décision : les tâches 001 à 030 sont décrites une par une dans `docs/taches/` et regroupées sur cette branche.
- Pour la suite : chaque nouvelle tâche part de `main` sur sa propre branche, avec sa PR et une CI verte avant fusion (règle de `CLAUDE.md`).
